# MulAn documentation

User, deployment, and API documentation for [MulAn](https://github.com/TEXTaiLES/MulAn), built with Material for MkDocs.

## Preview locally

```sh
python -m pip install -r requirements.txt
python -m mkdocs serve
```

Open <http://127.0.0.1:8000/mulan-documentation/>. To run the same strict build used for validation:

```sh
python -m mkdocs build --strict
```
